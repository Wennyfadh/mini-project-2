# Folder Penyimpanan Screenshot Sistem
Folder ini digunakan untuk menyimpan seluruh foto / tangkapan layar sistem untuk ditampilkan di README.md GitHub.

### Daftar Nama File Screenshot & Panduan Pengambilan:
1. `01_dashboard_katalog.png`      -> Buka `http://localhost/mini_projectwnny/index.php` (Tampilan utama katalog kartu produk pakaian & statistik).
2. `02_live_search_filter.png`    -> Ketik nama pakaian di kotak pencarian atau klik salah satu filter kategori (misal: "Jaket & Outerwear").
3. `03_modal_detail_produk.png`   -> Klik tombol "Detail" pada salah satu produk untuk menampilkan popup Quick View.
4. `04_tampilan_tabel.png`        -> Klik tombol "Tabel" pada switcher tampilan (di kanan atas katalog).
5. `05_tambah_produk.png`         -> Buka `http://localhost/mini_projectwnny/add.php` (Formulir tambah produk baju baru).
6. `06_validasi_error.png`        -> Pada form tambah produk, kosongkan input atau isi nama < 3 karakter lalu klik simpan untuk memicu pesan validasi.
7. `07_edit_produk.png`           -> Buka `http://localhost/mini_projectwnny/edit.php?id=1` (Halaman edit data baju berdasarkan ID).
8. `08_konfirmasi_hapus_csrf.png` -> Klik ikon hapus (tempat sampah) untuk memunculkan modal konfirmasi hapus aman dengan CSRF token.
9. `09_dark_mode.png`             -> Klik tombol tema bulan/matahari di kanan atas navbar untuk menampilkan mode gelap (Dark Mode).

*Catatan: Cukup ambil screenshot sesuai daftar di atas, rename filenya persis dengan nama file di atas, lalu letakkan di folder ini (`assets/screenshots/`). Gambar akan otomatis muncul di README.md GitHub!*
